# 绘 0.33.0 · 交互与布局 RC2

RC2 重点修复 RC1 实机反馈里的可读性、交互和首页信息密度问题，并继续保留 NekoBox / sing-box 成熟底座能力。

- 首页玻璃层提高可读性，背景仍可见但不再压住文字
- 首页固定显示实时上传/下载速度、本次连接累计流量和连接测试
- 原独立粉色圆形连接 FAB 改为统计玻璃条内的“连接 / 断开”胶囊按钮
- 修复节点/设置点击时出现突兀系统蓝色焦点框的问题，改为整卡按压回弹反馈
- 节点标题区域直接显示缓存延迟；未测速显示“— ms”，测速结果直接显示如“86 ms”
- 节点 URL 测速入口从三点菜单提到顶栏，减少操作层级
- 新增三种节点布局：紧凑列表、标准玻璃、舒适大卡，可在设置中切换
- 头像改为真实圆角裁切与柔和白色描边，不再是方形图片压在圆角底板上
- 移除背景中的大面积粉色径向圆球，樱花改成真实单片花瓣轮廓
- 樱花与背景漂移动画降低重绘频率，减少页面切换时的瞬时掉帧
- 路由、协议编辑等 Preference 页面统一使用可读性更高的透明磨砂玻璃
- 修复服务状态切换时 previousState 被覆盖导致按钮动画状态判断不准确的问题
- Snackbar 改为锚定可见的底部状态玻璃条，不再依赖隐藏逻辑 FAB

当前 RC APK 使用独立调试包名 `com.yingbao.hui.next.debug`，版本名 `0.33.0-rc2`，用于实机验证，可与正式包并存。
