# 绘 0.32.3 · Android 测试版

- 文件、粘贴和 HTTPS 导入的第一份 YAML 自动成为当前配置；已安装的旧版本若仍使用最早的“直连”默认值，仅迁移一次为“规则”。
- 运行时自动移除导入的桌面控制器和监听字段，不改原配置；缺少或关闭内核 DNS 的配置生成 VPN 所需的加密 DNS。连接前仍由 Mihomo 负责校验。
- 连接后读取 Mihomo 的真实策略组和节点；支持内核切换节点及真实 HTTPS 延迟测试。大组分批显示以减少滑动卡顿。
- 文件导入收纳至折叠入口，节点页显示连接错误；选择弹层改用透亮磨砂玻璃并调整动画。

这是测试版本。尚未在实际 Android 设备上核验 VPN 出口、DNS 泄漏和跨设备稳定性，不能当作已验证的正式版。
