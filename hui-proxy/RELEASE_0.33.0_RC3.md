# 绘 0.33.0 · 可读性与网格布局 RC3

RC3 继续处理 RC2 实机反馈，重点是去除系统蓝色焦点感、提高复杂背景下的可读性，并把节点页改得更接近现代代理客户端的双列卡片布局。

- 统一清理手机端默认焦点高亮和蓝色点击框，节点、Preference、抽屉选中态改为自定义玻璃反馈
- 提高玻璃层不透明度，并给动态背景增加轻度暗幕与降饱和处理，减少鲜艳背景对文字的干扰
- 抽屉使用独立高可读玻璃层，避免后方节点文字透进菜单造成重影
- 新增“双列网格”节点布局，并作为新默认布局；RC2 的默认标准布局会一次性迁移到网格
- 双列模式隐藏冗余操作图标，节点标题旁直接保留延迟；长按节点可进入编辑
- 新增“手动输入链接”，支持订阅 URL、VLESS/VMess/Trojan 等单节点分享链接
- 保留剪贴板、文件、扫码和手动新建等原有导入方式
- 修复 4K 背景在 1080P 手机上仍按完整尺寸解码的问题，按屏幕尺寸下采样，显著降低内存占用
- 背景位图由弱缓存改为强缓存复用，减少切页时偶发重新解码造成的卡顿
- 移除全屏背景漂移动画，樱花改为低频定时刷新并减少花瓣数量，降低主线程和 GPU 压力
- 继续保留 4K 原始背景文件、自定义背景、实时流量、连接测试、节点延迟显示和三档原有布局
- WebView、VPN/TUN、DNS、路由和 sing-box 底层逻辑未因本轮 UI 重构而更改

当前 RC APK 仍使用独立测试包名 `com.yingbao.hui.next.debug`，版本名 `0.33.0-rc3`，用于实机验证，可与正式包并存。
