# 绘 0.34.0 RC4 · 液态玻璃 UI 修复

RC4 不改双内核运行逻辑，专门恢复和优化“绘”的视觉与交互。

## 液态玻璃
- 降低卡片、抽屉和工具页的白色覆盖率，让自定义背景重新清晰可见。
- 顶部栏移除重复的双层玻璃叠加，改为单层透明玻璃。
- 玻璃表面改成轻渐变、高光边缘和更柔和的选中态，不再像白色塑料板。
- 底部状态条沿用同一玻璃系统，减少遮挡节点列表。

## 动画与交互
- 恢复壁纸低频慢漂移动效，并控制帧率以减少额外耗电。
- 樱花从 8 片恢复到 12 片，约 25fps，且置于暗幕上方增强可见性。
- 卡片、按钮和工具页 Tab 增加轻微缩放、淡入和位移动效。
- 节点选中态使用浅色表面 + accent 描边，普通节点保持通透。

## 工具与排版
- 重做备份页的字体、间距、按钮和选项分组。
- 重做 NAT 行为发现卡片，减轻大白气泡感并改善标题/正文/按钮层级。
- 抽屉选中背景进一步减淡，标题更新为 Box + Meta。
- 节点标题和协议标签重新分层，减少所有文字同一重量的杂乱感。

## 参考
- 交互层级参考 FlClash 的 CommonCard、ProxyCard、动画网格和按压反馈思路，但保留“绘”的现有布局与液态玻璃风格。

## 内核
- Box / sing-box 1.14.1 保持不变。
- Meta / Mihomo 1.19.31 保持不变。
- :control / :box / :meta / :bg 进程隔离与 CoreController 保持不变。

仍为 ARM64 / Android 7.0+ / debug 签名测试版。
