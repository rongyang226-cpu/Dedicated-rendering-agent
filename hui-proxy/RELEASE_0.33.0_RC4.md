# 绘 0.33.0 · 崩溃循环与诊断安全 RC4

RC4 优先修复一个会把用户困在系统分享面板里的严重问题，并顺手完成一轮崩溃、日志、生命周期和文件分享安全检查。

- 修复致命异常后自动重启到 `NB4A Crash` 分享面板的问题；崩溃时不再自动打开任何系统分享界面
- 崩溃改为只在应用私有目录保存一份本地诊断快照，下一次启动仅提示一次，可由用户主动进入日志页查看
- 防止重复点击“分享日志”产生多个分享面板；诊断导出失败会正常提示，不再形成循环
- 日志导出改为有上限：logcat 最多 1500 行、neko.log 尾部最多 1 MiB、崩溃快照最多 256 KiB
- 诊断日志分享前自动遮盖 VLESS/VMess/Trojan/SS 等节点链接、订阅 URL 路径与常见 token/UUID/密码字段
- 不再把完整设置数据库写入诊断日志，避免订阅链接、节点凭据等敏感配置被误分享
- FileProvider 从“整个缓存目录可分享”收紧为仅允许 `log/` 与 `backup/` 两个专用目录
- 备份分享移入独立缓存目录，文件名使用稳定时间格式，避免地区格式里的 `/`、`:` 等字符导致导出异常
- 修复备份与手动 URL 导入中的异步生命周期问题，避免页面退出后后台任务继续访问已销毁的 Activity/Fragment
- 节点布局在设置里切换后返回页面即可生效，不再需要重启；拖拽方向会随布局同步更新
- 修复 NAT/STUN 测试后台线程直接读取输入控件的问题
- 修复流量单位与 V2Ray 类型转换受系统语言区域影响的问题
- 继续保留 RC3 的双列节点、直接延迟显示、手动 URL 导入、可读性增强、4K 背景下采样和低负载樱花动画

本轮完整 APK 构建通过。Android Lint 仍能检测到一批来自上游 NekoBox 的旧依赖、旧 API、矢量图与无障碍规范技术债；为避免在紧急崩溃修复版里扩大回归范围，本次没有一次性升级整套依赖或改动代理核心。

测试包名仍为 `com.yingbao.hui.next.debug`，版本名 `0.33.0-rc4`，用于实机验证，可与正式包并存。
