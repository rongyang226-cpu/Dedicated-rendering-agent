# 绘 0.34.0 RC5 · 仪表盘与交互修复

RC5 继续保留 Box / Meta 双内核，只调整首页、节点页、路由页和可读性。

## 首页
- 默认启动不再直接显示节点列表，新增独立“仪表盘”首页。
- 仪表盘展示连接状态、实时上下行、累计流量、当前内核、内核版本/状态和内网 IPv4。
- 节点列表独立到“节点”入口；仪表盘提供直达节点按钮。
- 底部连接状态条优先用于仪表盘，不再默认覆盖节点列表。

## 可读性
- 去掉默认粉色文字体系，主色改为中性深灰。
- 路由规则说明、分组信息、协议标签等辅助文字统一为高对比深灰。
- 节点延迟仍保留绿/红状态色，避免丢失可用性提示。

## 交互修复
- 修复路由卡片内部可聚焦控件导致的系统蓝色焦点框。
- 路由开关缩放为原来的约 76%，减少突兀感。
- 节点页顶部只保留“搜索 + 一个更多菜单”，不再出现两个竖向省略号。
- 添加/导入、Meta YAML、手动测速、排序和清理操作统一收进单一更多菜单。

## 自动测速
- 节点页前台时每 60 秒进行一次静默 TCP 延迟测试。
- 自动测速不弹窗口；已有测速任务运行时自动跳过本轮。
- DNS 解析优先使用当前网络，失败时自动回退普通系统解析。

## 内核
- Box / sing-box 1.14.1 保持不变。
- Meta / Mihomo 1.19.31 保持不变。
- 双内核进程隔离和 CoreController 保持不变。

仍为 ARM64 / Android 7.0+ / debug 签名测试版。
