# 绘 0.34.0 RC6 · 布局与配置中心

RC6 保持 Box / Meta 双内核不变，重点重做主布局、配置编辑和交互性能。

## 布局
- 移除旧的底部常驻连接白条。
- 新增底部大型液态玻璃 Dock，包含：仪表盘、节点、配置、设置四个小气泡。
- 四个主页面首次创建后缓存，后续使用 hide/show 切换，减少反复 inflate 带来的顿挫。
- Dock 为内容区预留安全空间，不遮挡设置页和配置页最后一项。
- 二级页面会清除 Dock 选中态，返回主页面时恢复正确高亮。

## 仪表盘
- 新增液态玻璃主连接/断开按钮。
- 保留当前内核、状态、实时速率、累计流量和内网 IP。
- 连接按钮加入 600ms 防重复点击，避免快速连点导致状态打架。
- 内核状态文件改到 IO 线程读取；内网 IP 改为后台低频刷新，降低主线程卡顿。

## 配置中心
- Meta 可直接编辑当前 Mihomo YAML，保存或保存并应用。
- Meta URL 来源完整保存在本机；远程更新前自动备份旧 YAML，本地编辑后仍可继续更新来源。
- Box 普通节点支持编辑全局 JSON 覆写。
- Box 完整自定义 sing-box 配置使用独立本地覆写层，订阅底稿仍可更新，本地修改不会被覆盖。
- 没有远程来源时“更新来源”自动置灰。
- 保存/应用/更新均加入忙碌锁，避免重复点击；编辑后显示“未保存”。

## 其他优化
- 订阅更新的连接状态统一读取当前 Box / Meta 状态，不再依赖旧 serviceState。
- 清理固定粉色 Dialog 强调色，统一到绘的中性液态玻璃配色；用户主动选择的主题色仍保留。
- Box / sing-box 1.14.1 与 Meta / Mihomo 1.19.31 均保持不变。

ARM64 / Android 7.0+ / debug 签名测试版。
