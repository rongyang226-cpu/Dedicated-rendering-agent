# 绘 0.34.0 RC11 · 原生分页与稳定节点

RC11 不再继续给 Fragment 切换打补丁，而是把四个主页面改成常驻分页结构，同时重做节点刷新路径和配置入口。

## 主页面分页
- 仪表盘、节点、配置、设置改为 ViewPager2 常驻四页，页面真正横向滑动，不再叠加 Fragment 做“网页式换页”。
- 四个主页面预加载并保留状态，底部切换不会反复创建页面；背景层固定不动。
- 页面移动只保留很轻的透明度和缩放辅助，主要位移交给系统分页动画。
- 底栏点击和左右滑动统一到同一分页状态，二级页面仍独立覆盖并可返回当前主页面。

## 节点列表稳定性
- 测速、状态和选中变化改为 payload 局部刷新，只更新延迟文字和运行状态，不重新绑定整张卡片。
- 后台刷新不再按实时延迟重新排序；当前节点 ID 顺序会持续保持。
- 只有用户主动修改排序规则时才重新排序一次。
- Grid 模式关闭长按拖拽，避免滑动或长按时误触造成节点位置变化。
- 保留固定卡片高度、固定延迟宽度、关闭 ItemAnimator/LayoutAnimation 等稳定措施。

## 配置与导入
- 底部原“分组”正式改名为“配置”。
- 订阅、二维码、剪贴板、URL、文件、Meta YAML/URL、手动节点和新建分组统一移动到配置页的“添加 / 导入”。
- 节点页只保留搜索、测速、排序、更新订阅、清理结果等节点操作，不再混入导入入口。

## 视觉与流畅度
- 玻璃填充、白边和底栏阴影继续降低，减少乳白塑料按钮感。
- 樱花装饰限制到约 30 FPS，把渲染预算优先留给页面滑动和列表滚动。
- 启动过场加入背景推进、头像/内容缩放和抬升，进入主界面不再只是简单淡入。

## DNS
- FakeIP 迁移到 sing-box 1.12+ 的 typed fakeip DNS server 格式。
- 不再生成已废弃的 `dns.fakeip` legacy options，避免当前警告以及 sing-box 1.14 移除旧格式后的启动问题。

## 内核
- 延续 RC10 的自动内核模式：普通节点使用 Box / sing-box，Meta / Mihomo YAML 使用 Meta。
- 保留手动 Box / Meta 选项和统一 CoreController 路径。

## 兼容性
- 当前测试包继续面向 ARM64 Android 设备。
- 与 RC10 使用相同 Debug 签名，可直接覆盖安装。
