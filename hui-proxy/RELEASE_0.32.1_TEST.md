# 绘 0.32.1 · 安卓测试版

延续 0.32 的 Mihomo VPN 基础。首页增加规则、全局、直连模式；设置中可选择导入配置的 DNS、AliDNS DoH、Cloudflare DoH，并选择是否在 TUN 内拦截全部 53 端口。选择会写入下次启动的核心配置，且在连接前通过 Mihomo 校验。背景和卡片仍采用透明玻璃，文字、层次和底栏已调整。

请先断开 VPN 再修改网络设置。严格拦截仅覆盖 VPN 内 53 端口；不能保证控制浏览器自带加密 DNS。导入的机场 DNS 如有特殊分流，选择其他 DNS 来源会覆盖该段配置。

此包仍需手机实测 VPN 出口、DNS、网络切换和后台保活。与 0.32 使用同一签名和包名，可以正常覆盖 0.32 测试版；旧莹宝签名不同，无法直接覆盖。
