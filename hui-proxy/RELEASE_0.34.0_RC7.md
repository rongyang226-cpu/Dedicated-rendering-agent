# 绘 0.34.0 RC7 · 交互与动画

RC7 保持 Box / Meta 双内核不变，重点修复真机反馈中的顶部触摸、菜单样式、分组入口、延迟交互和页面动画。

## 顶部与菜单
- AppBar 正式避让状态栏，不再让时间/信号区域压住标题栏触摸区。
- Toolbar 高度与状态栏 inset 分离，顶部搜索、菜单和返回/抽屉按钮获得正常可点击区域。
- 三点菜单使用绘的液态玻璃 Popup 主题，不再使用系统 DayNight 原生样式。

## 主导航
- 底部第三个主入口由“配置”调整为“分组”。
- 主入口变为：仪表盘 / 节点 / 分组 / 设置。
- 原始配置编辑器降为分组页二级功能，通过菜单“编辑原始配置”进入。
- 配置编辑器内部导航 ID 保留但不再在抽屉中突出显示。

## 节点与测速
- 节点卡延迟标签支持直接点击，单独重测当前节点 TCP 延迟并即时刷新。
- 不可用节点也可以点击重试；长按不可用标签查看上一次错误。
- 60 秒静默自动测速继续保留，并复用同一套 TCP 测速逻辑。
## 动画与流畅度
- 主页面继续缓存，二级页改为临时覆盖，不再 replace 掉已缓存主页面。
- 页面切换新增 180ms 淡入 + 轻微位移动画，返回主页面直接恢复缓存实例。
- Dock 选中项增加轻微抬升、缩放和透明度过渡。
- 樱花改为跟随 VSync 刷新，背景漂移由约 25fps 提升到接近 60fps。
- 液态按压动画缩短并取消与 stateListAnimator 的双重缩放冲突，减少点击时的顿挫/弹跳。
- 从原始配置编辑页返回时回到进入前的主 Dock 页面。

## 核心
- Box / sing-box 1.14.1 保持不变。
- Meta / Mihomo 1.19.31 保持不变。
- ARM64 / Android 7.0+ / debug 签名测试版。
