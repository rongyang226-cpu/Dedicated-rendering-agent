# 绘 0.32 · 安卓测试版

这是代理连接测试版，已集成 Mihomo 原生核心、Android VPN/TUN、YAML 文件导入、核心配置校验和真实上/下行速率读取。背景可在设置中更换，页面使用与后台一致的透明玻璃样式。

启动方式：导入完整的 Mihomo `.yaml` 或 `.yml` 配置，选中配置，点击连接并授权 VPN。JSON 仅保存为草稿，不支持连接。订阅更新、节点测速、独立分流编辑和 sing-box 尚未接入，界面对应入口不可用。

**目前缺少 Android 真机联网回归测试。** VPN 图标出现只说明系统建立了 TUN；请在手机上核对实际公网 IP、DNS 和断开后的恢复。测试结果确认前请勿把它当作成熟代理客户端。反馈故障时提供 Android 版本、配置的脱敏片段及错误提示，不要上传完整订阅或密码。

安装提示：此测试版与旧莹软件同包名，但签名不同，无法直接覆盖安装；请先自行备份旧版数据并卸载旧版，再安装绘。VPS 上的 TG/QQ 聊天和网页版后台不受 APK 卸载影响。
