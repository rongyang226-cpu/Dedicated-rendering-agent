# 绘 0.32.2 · 安卓测试版

- 首页始终保留开启／断开连接按钮，并将选择配置单独放在旁边。
- 连接模式、DNS 来源与拦截范围改用应用内玻璃弹层，不再出现 Android 默认白色下拉列表；去除点击时的蓝色方框。
- 支持从 HTTPS 配置链接下载一次 Mihomo YAML、粘贴 YAML 和选择文件导入。配置存到应用私有目录，连接前仍由 Mihomo 内核验证。链接导入暂不提供定时更新；不支持节点分享链接和纯 Base64 订阅。
- 内置 DNS 可选择是否让查询遵循分流规则（Mihomo respect-rules）；节点域名使用专用解析器。沿用导入配置 DNS 时不覆盖其分流策略。
- 低内存设备自动关闭耗费性能的多层模糊和花瓣动画，保留页面背景与玻璃配色。

这是测试版本。实际 VPN 连通性、DNS 出口、不同厂商设备上的界面表现仍需在真机核验。
