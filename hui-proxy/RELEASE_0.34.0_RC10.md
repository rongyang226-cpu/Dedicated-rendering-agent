# 绘 0.34.0 RC10 · 平面切页与自动内核

这一版继续按真机反馈收口 UI 和交互，不再用叠加式淡入淡出。

## 页面切换
- 底部四个主页面改成完整宽度横向平移：新页面从对应方向推入，旧页面同步推出。
- 背景层保持静止，不跟着页面移动，不再出现两张页面叠在一起的感觉。
- 二级页面返回时使用反向平移；同时修复非首页按返回键时可能停在原页的问题。

## 节点列表稳定性
- Grid 节点卡片固定高度、标题固定两行、延迟标签固定宽度，延迟数字变化不再触发布局抖动。
- RecyclerView 关闭 ItemAnimator 和 LayoutAnimation，测速刷新只更新内容，不做卡片位移动画。
- 自动测速从 60 秒降低为 5 分钟一次，滚动过程中会跳过自动测速。
- 重新载入节点时不再强制滚回顶部，避免列表突然跳位置。
- 去掉选中节点的深色/蓝色描边，只保留轻微玻璃亮度差异。

## 液态玻璃
- 降低卡片乳白填充和强描边，改成更薄、更透的中性玻璃层。
- 底栏与标签取消粉紫色高光，不再像一组廉价按钮。
- 设置项与对话框同步降低实色感，背景可读性仍由独立柔光层保证。

## 启动过场
- Android 12+ 系统启动页改为绘的暖色启动底和头像，不再先闪纯白。
- Bootstrap 增加短暂的背景/头像缩放淡入过场，再自然进入主界面。

## 自动内核
- 新增“自动 · 按节点/配置选择”模式，并作为升级后的默认模式。
- 点击普通 NekoBox 节点会自动选择 Box / sing-box。
- 导入 Meta / Mihomo YAML 会自动切到 Meta。
- 保留手动 Box / Meta 选项；统一 CoreController 负责后续协议扩展时的内核选择。

## 兼容性
- 继续面向 ARM64 Android 设备。
- 与 RC9 使用相同 Debug 签名，可直接覆盖安装。
