# 绘 0.34.0 RC8 · 真机兼容与玻璃统一

RC8 继续保持 Box / Meta 双内核架构，集中修复 RC7 真机反馈中的视觉统一、连接兼容、节点列表稳定性与切页白闪。

## 液态玻璃与可读性
- 分组设置页补上统一 Preference 液态玻璃卡片，不再让文字直接压在高对比背景图上。
- Preference 普通态也保留透明渐变玻璃与描边，不只按下时才出现玻璃效果。
- Material AlertDialog 统一使用半透明玻璃 Surface、深色正文与 24dp 圆角。
- 分组设置容器改为填满剩余区域，长列表在不同尺寸/比例屏幕上布局更稳定。

## 节点列表稳定性
- 静默测速结束后不再整组 reload，避免 Grid 突然重排、跳位置或滚动位置变化。
- 每个节点只刷新自己的延迟状态。
- 关闭 RecyclerView change cross-fade，延迟更新只改文字/状态，不再让整张节点卡闪动。

## Box / Meta 兼容
- 当前选中的内核没有可用配置时，会自动回退到另一套已有配置的内核。
- 例如选中 Meta 但只有普通 VLESS / Box 节点时，连接会自动切回 Box，不再强制要求先导入 Meta YAML。
- 自动回退下沉到统一 CoreController，仪表盘、快捷开关、Tile、开机自动连接与重载入口行为一致。

## 动画与白闪
- 页面切换去掉 alpha 淡入淡出，只保留非常轻的横向位移动画，避免透明壁纸页面露出底色产生白光闪烁。
- 背景与樱花动画使用硬件层，减少和 RecyclerView / 布局更新争抢 UI 线程。
- 节点状态刷新不再触发卡片级 change 动画，滚动时更稳定。

## 核心
- Box / sing-box 保持现有版本。
- Meta / Mihomo 保持现有版本。
- ARM64 / Android 7.0+ / debug 签名测试版。
