# 绘 0.34.0 RC9 · 稳定性与连接诊断

RC9 针对真机反馈继续收口：节点列表乱跳、页面切换白闪、玻璃层可读性、Meta 连接失败后看不到真实原因，以及高频 UI 刷新带来的卡顿。

## 液态玻璃与可读性
- 提高主卡片、标签与底栏玻璃层的不透明度和白色边缘，高对比壁纸下文字更清楚。
- 背景轻度降饱和并加入柔和亮层，不再用暗色遮罩把黑字压进红色背景。
- 配置编辑器、扩展键盘和链式设置页继续统一液态玻璃外观，清掉残留的实色灰条与实色按钮背景。

## 节点列表稳定性
- 节点布局参数只在 ViewHolder 初始化时设置，不再每次延迟刷新都重新改 margin / padding / 圆角。
- 移除节点卡片的第二套 StateListAnimator，避免与液态按压动画互相抢 scale。
- 静默测速不再对同一批节点二次广播刷新。
- 节点卡绑定直接复用主界面的内核状态快照，取消每张卡片单独启动协程并读取状态文件。

## 页面动画与流畅度
- 页面切换改成近乎不透明的轻微位移，避免过渡时露出 Window 底色形成白光闪烁。
- 禁用窗口预览闪屏。
- 慢速壁纸漂移动画降低刷新频率，把主线程/GPU 预算优先留给列表滚动、测速与切页。

## Meta / Mihomo 连接
- TUN 改为非阻塞模式，与 Clash Meta for Android 的实现保持一致。
- 修复 Meta 启动失败后 ERROR 状态被 Service 销毁流程立即覆盖成“未连接”的问题。
- 仪表盘在异常状态优先显示真实错误原因，下一次连接失败可以直接看到具体问题，不再只显示 Mihomo 版本。
- 保留 Box / Meta 自动回退逻辑。

## 兼容性说明
- 本测试包继续面向 ARM64 Android 设备。Meta 自带的定制 JNI 当前仍只有 arm64-v8a；32 位或 x86 设备暂不宣称 Meta 完整兼容。
- 当前包使用与 RC8 相同的 Android Debug 签名，可直接覆盖安装 RC8。
