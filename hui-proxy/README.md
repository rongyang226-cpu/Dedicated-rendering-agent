# 莹代理 · Android 独立工程

状态：连接层设计与安全策略校验已开始；已有可安装的界面与本机配置预览 APK（/opt/ying-proxy-android/out/Hui.apk）；尚未接入 VPN 或任何内核，不具备代理连接能力。
此模块位于莹的现有 GitHub 仓库 hui-proxy 分支；与莹宝应用分包，与现有后台共享节点和账号接口。不要把“已配置”显示成“已连接”。

## 架构
- 安卓原生 VpnService 唯一负责 VPN 授权、TUN、前台服务、套接字 protect、网络切换和断线状态。
- CoreAdapter 三实现分别封装 sing-box、Mihomo、Xray；内核切换先停旧核心，验证新配置，再启动新核心，失败显式显示断开。
- 一个时刻只有一个核心、一个 VPN。订阅更新先验证格式和签名/来源，再原子替换；节点凭证只留在设备或受保护的用户账户。
- 同一套“国内直连、海外代理、AI、视频、游戏、自定义”规则分别翻译为三个内核的配置；无法等价翻译时拦截或提示，绝不静默降级。
- DNS 源可选“软件内置”或“导入配置”；规则源独立选。DNS 入口必须由 VPN 接管；按域名/地域选解析器；IPv6 默认禁用，需要时必须同时接管其 DNS 和路由。
- UDP/QUIC 默认走匹配规则的代理，按需要允许用户显式选择阻断。不要全局丢 UDP 后谎称无泄漏。
- 断线阻断依赖用户在安卓系统开启“始终开启 VPN”和“阻止无 VPN 连接”；应用只检测并引导，不宣称可自行代替系统开关。
- Android 私有 DNS / 浏览器 DoH / HTTP3 需要实际设备测试；应用层识别与阻断受系统限制，不宣传百分之百防泄漏。
- UI 沿用绘梨衣壁纸和透明液态玻璃：连接、节点、内核、流量速览；其余折叠。动态花瓣遵从减少动画设置，弱设备自动降级。

## 验收
1. 以实际节点分别测试三核心 VLESS Reality / gRPC-H2 / HY2 / Trojan 支持矩阵。
2. 测试 VPN 授权、重连、切核、Wi-Fi/蜂窝切换、后台保活和失败后无直连回退。
3. 在规则/全局模式分别测 IPv4、IPv6、DNS、UDP、QUIC、指定应用和本机代理 IP；以外部出口与连接日志双向对照。
4. 导入规则/DNS 无效、订阅超时、错误密码、节点不可达时连接状态必须真实、可恢复。
