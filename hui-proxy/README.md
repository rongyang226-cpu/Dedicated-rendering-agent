# 绘 · 莹现有仓库中的 Android 代理模块

分支：`hui-proxy`。这是一款正在开发的 Android 客户端，沿用后台的头像、壁纸和玻璃界面。它与仓库中的莹宝应用分包，未改动现有后台和莹宝功能。

## 当前可以使用的内容

- 安装界面预览 APK，查看首页与本机配置列表。
- 从系统文件选择器导入最多 1 MB 的 JSON/YAML 文件；文件只保存在应用私有空间。
- JSON 导入时检查 UTF-8、语法和顶层代理配置字段；YAML 只能存为待解析草稿。
- 导入采用临时文件和同目录替换，读取配置在工作线程执行；可以选择草稿或删除。
- 不提供 VPN 连接：界面中的未接通功能已禁用，草稿绝不会显示为已验证或已连接。

## 下一步实现顺序

1. 解析与规范化节点/订阅，调用真实内核的配置检查；无效配置不得启动。
2. 集成 sing-box 核心和 Android VpnService，打通 TUN、DNS、路由、网络切换和状态日志。
3. 真机核对出口、DNS/IPv6/UDP、切网、权限拒绝和后台恢复，之后发布可代理版本。
4. 再接入 Mihomo 的对应功能与能力检测；Xray 属于后续扩展，未集成。
5. 高级分流、测速、流量、连接和诊断须从核心获得真实数据，逐项完成回归。

后台目前提供账号/设备和订阅生成接口；绘还未调用这些接口。服务端运行的 sing-box 不等于 Android 已集成内核。
